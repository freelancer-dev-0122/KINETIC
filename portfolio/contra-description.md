# KINETIC // K-1 AERO Launch Experience

KINETIC is a high-performance eCommerce product launch concept for the fictional K-1 AERO racing sneaker, built to demonstrate top-tier creative frontend execution, smooth 60fps animations, and production architecture.

### Highlights
- **3-2-1 + GO Split Loader**: Diagonal countdown animation transitioning seamlessly into the hero.
- **Instant Colorway Engine**: Global re-theming across typography, accents, and 3D shoe models with zero layout shift.
- **Scroll-Driven Product Run**: Pinned canvas experience with dynamic opposite-side text positioning and technical hotspots.
- **Exploded Anatomy Blueprint**: Interactive layer scrub demonstrating sole plate geometry and PEBA foam.
- **Deterministic Size Finder**: Mathematical fit algorithm with live ruler dragging, foot outline visualization, and stock checks.
- **Live Drop Pass Ticket**: 3D cursor-tracking boarding pass with tear-off confirmation stub, confetti burst, and calendar sync.

### Skills
`GSAP Animation`, `ScrollTrigger`, `Lenis Smooth Scroll`, `Creative Engineering`, `Interactive Design`, `Performance Tuning`, `CSS Architecture`, `JavaScript`
