# KINETIC // K-1 AERO Launch Experience

KINETIC is an Awwwards-caliber launch platform for the fictional K-1 AERO sneaker, demonstrating elite creative frontend engineering.

### What I Built
- **3-2-1 + GO Countdown Loader**: Fullscreen diagonal split sequence into the hero.
- **Dynamic 3-Colorway Theme Engine**: Site-wide palette and 3D shoe re-theming via CSS variables.
- **Pinned Product Run**: Scroll-scrubbed motion path with side-swapping chapter text.
- **Interactive Tech Blueprint**: Exploded anatomy view with draggable layers.
- **Race Simulation**: Real-time performance benchmark with live telemetry.
- **Drop Pass Reservation**: 3-step form with 3D ticket tilt, tear-off stub, and .ics calendar sync.

`GSAP`, `ScrollTrigger`, `Lenis`, `Creative Development`, `Web Animation`, `Performance Optimization`, `JavaScript`, `UI/UX Design`
